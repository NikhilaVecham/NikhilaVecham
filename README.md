### 🛒 SuperKart — Sales Forecasting & ML Model Deployment

Built an **end-to-end machine learning solution** for SuperKart, a retail chain operating supermarkets and food marts across multiple city tiers.

The objective was to predict **outlet sales revenue for the upcoming quarter**, helping the business improve inventory planning and make data-driven regional sales decisions.

### 🔍 What I Worked On

* Performed **Exploratory Data Analysis (EDA)** to understand sales patterns and key business drivers
* Cleaned and preprocessed data for machine learning
* Built and compared regression models for sales prediction
* Performed **hyperparameter tuning** to improve model performance
* Selected the best-performing model for deployment
* Built a prediction **API using Flask**
* Containerized the application using **Docker**
* Developed an interactive interface using **Streamlit**
* Deployed the ML application using **Hugging Face**

### 🛠️ Tech Stack

`Python` `Pandas` `NumPy` `Scikit-learn` `EDA` `Machine Learning` `Hyperparameter Tuning` `Flask` `REST API` `Docker` `Streamlit` `Hugging Face`

### 💡 Key Learning

This project gave me hands-on experience with the complete machine learning lifecycle:

**Business Problem → EDA → Data Preprocessing → Model Building → Hyperparameter Tuning → Model Evaluation → API Development → Containerization → Deployment**

It helped me move beyond model experimentation in notebooks and understand how a trained machine learning model can be transformed into a **deployable application that can generate predictions for real-world users**.
